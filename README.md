## Сетевое программирование

*Темы*:
1. Введение в сетевое программирование.
   - Связь с системным программированием (в плане IPC).
   - Понятие сокета. Сокеты Беркли.
   - Простое взаимодействие "один клиент - сервер" (каталог `client_server`).
2. Сериализация и десериализация данных.
   - Преобразование произвольных данных для передачи по сети в виде потока байт (каталог `serialization`)
3. Обработка нескольких подключений.
   - Асинхронная обработка подключений с использованием потоков (каталог `async_connections`)
   - Синхронная обработка подключений с использованием опрашивания (каталог `poll_connections`)

*Задания*:
1. Переписать интерфейс сокетов на ООП (на основе кода из каталога `client_server`).
2. Написать игру камень-ножницы-бумага с двумя соединениями (на основе кода из каталога `client_server`).
3. Написать чат между произвольным количеством пользователей (на основе кода из каталога `async_connections`).
   - Необходимо выводить никнейм и сообщения **только на сервере**.
4. Доработать задание №3 так, чтобы все клиенты так же получали сообщения (на основе кода из каталога `async_connections` + кода, полученного в задании №3).
   - Необходимо сохранять список дескрипторов для возможности их использования в других потоках.
   - При получении данных на сервере отправлять данные на все клиенты, кроме текущего.
   - На клиенте в отдельном потоке реализовать асинхронное получение данных.
